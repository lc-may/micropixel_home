# Guest 音乐界面控件

音乐终端复用已有 Scene、Label、TextButton、ImageButton、Flex/Grid 与 Input 服务。
界面按歌曲列表、底部迷你播放器、独立播放页组织，导航保持每日推荐、我的音乐和搜索。
参考[网易云官方手机版截图](https://apps.apple.com/cn/app/id590338362)的内容层级、封面、播放控制与收藏入口。

## SDK 能力

| 能力 | SDK 入口 | 用途 |
| --- | --- | --- |
| 文本、图片、布局、普通按钮 | 原有 Scene / ui | 标题、头像、封面、搜索与导航 |
| 图标、选中与等待状态 | `Container::CreateIconButton` | 播放/暂停、前后切歌、红星 |
| 双行列表项及独立尾部操作 | `Container::CreateListItem` | 歌名、歌手、歌单、收藏按钮 |
| 触摸滚动及内容裁剪 | `Container::CreateScrollView` | 固定行池复用、滚动条 |
| 拖动数值、提交与取消 | `Container::CreateSlider` | 播放进度与松手跳转 |

这些控件只组合 Guest Scene 和已有输入事件，不新增 Core import 或 Service ABI。
节点由 Scene 持有，控件不可复制，可移动；`Destroy()` 显式销毁子树。
搜索输入使用现有 `Input::EnableText/ReadText` 与文本按钮组合。

## 输入与状态契约

- Slider 接受 `uint32_t` 范围，最大值为零时不接收拖动。单次手势只跟踪一个 touch ID，
  拖动时提供预览，抬起返回 `committed`；取消恢复手势前的值。外部进度更新不会打断拖动。
- ScrollView 将偏移夹在内容边界内，超过 8 像素才判定拖动。应用在拖动时重置列表项交互，
  并在抬起时消费该手势，避免滚动变成播放或收藏。`at_end()` 查询是否触底，应用在手势结束后追加数据。
- ListItem 将正文与尾部按钮分为独立命中区；文本裁剪在按钮之前，尾部点击不传递给正文。
  标题和副标题最多各 128 字节，过长输入返回错误并保留原内容。
- IconButton 的选中状态由应用设置，等待状态阻止重复点击；网络确认前不自动翻转收藏状态。
- 数据集更换时重置行交互与滚动位置。网易云使用 8 个列表项复用可视行，绘制和拖动不创建新控件。
  向当前数据集追加内容时保留滚动位置，加载中的重复手势不发出额外请求。

PC 系统字体使用桌面 CJK 字体绘制文字，并回退到同角色的内置 Latin 字体绘制 SDK 稳定符号。
播放、暂停、刷新等图标复用 `sdk/symbols.hpp`；应用自选的红星使用系统中文字体。

## 音乐收藏

红星表示加入或移出“我喜欢的音乐”，调用 Guest 中的 `/weapi/radio/like`，
状态通过 `/weapi/song/like/get` 同步。等待服务器确认时禁用重复操作，切换页面不会取消已发出的写请求。
失败时保留旧标记并重新读取服务端状态；退出、账号切换和 301 失效清除个人列表和收藏状态。
Cookie/CSRF 只发送给网易云接口，头像与封面下载不携带账号 Cookie。
