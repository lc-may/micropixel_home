# 家庭面板界面

Home、天气和日历闹钟以用户提供的 [720×720 设计系统](../ui_design/index.html)为当前视觉规范，
对应其中的 01 主页、02 天气、03 闹钟、12 响铃打断，以及色彩、排印和控件规格。
音乐保留现有网易云内容与播控布局，共用面板配色。

## 画布和视觉

使用 720×720 逻辑坐标、安全边距 24、卡片间距 18，以及 24–33 的圆角。
背景 `#101214`，卡片 `#1B1F23`，浮起表面 `#242A2F`，分隔线 `#2B3238`；
正文 `#F5F7F8`，辅助文字 `#8C979E`，强调 `#E8A15C`，强调底上的文字 `#1A1305`。
主时钟和闹钟使用 96 px 数字，天气主温度使用 126 px 数字；中文使用 SDK 现有的 16/20/26/32 字号角色。
常用操作采用 84 px 触摸区域，开关的可见尺寸为 84×48。保留键盘输入与中文输入法。

Home 由 Host LVGL 绘制，天气和时钟仍由 Guest Scene SDK 绘制。
数字采用 Noto Sans SemiBold 的本地字形子集；图标采用 Google Material Symbols Rounded，
按面板配色生成共享图集。来源、固定版本和许可证见 [图标资源](../../guest/sdk/ui/icons/README.md)
与[第三方声明](../../THIRD_PARTY_NOTICES.md)。运行时无需获取字体或图标。

## 页面和交互

| 页面 | 结构与功能 |
|---|---|
| Home | 顶部时间/日期/天气主卡；2×2 卡片显示闹钟、日历事项、音乐、应用入口。音乐卡片保留播放/暂停与下一首 |
| 应用目录 | 本地应用与官方市场入口；底部调节系统音量、关闭当前应用 |
| 天气 | 大号温度、当天高低温、5 个小时预报、未来 3 日温度范围；底部显示湿度与风速 |
| 选择城市 | 点击天气页左上城市；首页 10 个常用城市，按省份进入 34 个省区的 394 个城市/地区，列表支持滚动；右上刷新天气 |
| 闹钟 | 下次闹钟主卡、开关、当前闹钟与已保存的事项摘要；底部进入日历或事项 |
| 设置闹钟 | 点击主卡或右上加号进入；调整时/分、每天/单次、保存、10 秒测试、时区与同步时间 |
| 日历 | 月份切换与日期选择；点击月份回到今天，右上加号为选中日期添加事项 |
| 事项 | 最多六条，可编辑、完成/恢复和删除；底部添加事项 |
| 响铃 | 深色暖光背景、大号时间、提醒标题，提供停止响铃和暂停音乐两个操作 |

主页使用真实已有能力映射四个卡片，不显示设计示例中的灯光、空调或室内传感器数值。
闹钟页保留一个主闹钟和六条事项，列表展示实际保存的提醒；底部入口对应日历和事项。

Esc/Home/F1 返回 Home，音乐继续播放并保留登录和队列；点击音乐卡片复用原实例。
在应用目录点击“关闭当前应用”才停止对应 Session，其他应用继续运行。
市场中的 Esc 返回上级；响铃中的 Esc/回车停止响铃，保持输入优先级和音频焦点契约。

## 天气数据与图标

天气直连 [Open-Meteo Forecast API](https://open-meteo.com/en/docs)，请求 current、hourly 和 daily 数据，
保留最多 5 小时和 4 天（今天与未来 3 日）。城市使用北京时间。
不额外请求空气质量，底部展示已有的湿度/风速；服务端缺少、为 null 或范围无效的数据显示 `--`。
小时/日预报缺失不影响当前温度。请求失败保留上次成功结果和缓存，页面明确显示更新失败。
缓存版本 4 保存新版城市选择与预报；按需求重置旧三城列表的选择和缓存。保留来源署名。

城市列表离线内置，首屏依次为上海、北京、广州、深圳、杭州、成都、武汉、南京、重庆、西安。
这是常用城市快捷顺序。省份和城市列表复用 SDK ScrollView 与 18 个按钮，滚动松手不会误选；
所选城市在 Host 重启后保留。位置数据来源、固定版本与许可见
[城市数据](../../guest/apps/weather/data/README.md)。天气继续按经纬度直连 Open-Meteo，无需额外地理编码请求。

| WMO 天气 | Material 图形 |
|---|---|
| 0 / 1–2 / 3 | 晴 / 晴间多云 / 阴 |
| 45、48 | 雾 |
| 51–57 | 毛毛雨 |
| 61–67、80–82 | 雨与阵雨 |
| 71–77、85–86 | 雪与阵雪 |
| 95、96、99 | 雷暴 |
| 未知或未获取 | 不可用图标 |

Home、主天气和预报卡片使用同一组天气映射。其他页面的闹钟、日历、事项、应用、返回、增删、
刷新和播控图标也来自 Material 圆润风格，可在统一图集中复用。

## 持久计划和 SDK

主闹钟仍使用计划 1，临时测试使用计划 2，事项使用计划 3–8；额度、持久化、关闭后的响铃和错过不补响规则不变。
事项标题/时间保存在 Host 计划，手动完成标记保存在 App 私有 KV。
Clock Widget 的可选 `OpenPage` 消息仍用 U32 0=闹钟、1=日历、2=事项。
七个 Core imports 和 ABI 布局不变，既有音乐、后台任务与多实例策略沿用原实现。

通用能力见 `sdk/ui/panel.hpp`、`numerals.hpp`、`material_icons.hpp`、`weather_icons.hpp` 与 `sdk/calendar.hpp`。
字形和图标按 Activity 创建共享纹理，页面切换复用，销毁 Activity 时回收。
运行命令与自动验证见[面板运行指南](../development/panel-ui.zh-CN.md)。
